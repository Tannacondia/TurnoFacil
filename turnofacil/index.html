¿La reserva es real?＋

No. TurnoFácil en esta versión es una demostración de portfolio. No contactamos a un profesional ni enviamos confirmaciones.

¿Qué pasa con mis datos?＋

Se almacenan únicamente en el almacenamiento local de este navegador para mostrar cómo funcionaría la agenda. Podés borrar los datos desde “Consultar o cancelar una reserva”.

¿Puedo cambiar o cancelar un turno?＋

Podés consultar las reservas con el correo usado y cancelar una reserva de demostración.

¿Los horarios están disponibles en tiempo real?＋

La disponibilidad se calcula con horarios ficticios y las reservas guardadas en este navegador. Para coordinar reservas reales hace falta un backend compartido.
